# Project 2: Exploratory Data Analysis & Visualization

A beginner-friendly data science project focused on exploring text statistics and visualizing dataset distributions using `matplotlib` and `pandas`.

---

### 🎯 Objectives:
- Load emotion text data from Hugging Face `datasets`.
- Derive statistical summary metrics (character length, word count).
- Create informative visualizations including bar charts, histograms, and box plots using `matplotlib`.
- Extract data insights regarding text lengths across categorical labels.

### 📁 Link to Implementation:
- Notebook: [notebook.ipynb](notebook.ipynb)

### 💡 Requirements:
- `datasets`
- `pandas`
- `matplotlib`
