# Project 3: Data Manipulation & Aggregation

A beginner-friendly project demonstrating advanced data manipulation, custom feature engineering, group-by statistics, and pivot table cross-tabulation in `pandas`.

---

### 🎯 Objectives:
- Load sentiment text data from Hugging Face `datasets`.
- Engineer custom features (character count, word count, uppercase ratio, average word length).
- Subset and filter data using complex boolean logic.
- Perform multi-metric group-by aggregations (`mean`, `median`, `std`).
- Create pivot tables (`pd.crosstab`) and plot aggregate metrics.

### 📁 Link to Implementation:
- Notebook: [notebook.ipynb](notebook.ipynb)

### 💡 Requirements:
- `datasets`
- `pandas`
- `matplotlib`
