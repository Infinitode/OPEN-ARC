# Project 1: Data Cleaning and Text Filtering

A beginner-friendly data science project demonstrating how to clean text data, detect duplicate entries and missing values, and perform automated text moderation/profanity filtering using the `valx` package.

---

### 🎯 Objectives:
- Load text datasets using Hugging Face `datasets`.
- Perform data quality checks using `pandas` (missing values, duplicate rows).
- Clean whitespace and format strings for analysis.
- Apply `valx` functions (`detect_profanity`, `remove_profanity`) for text moderation and filtering.

### 📁 Link to Implementation:
- Notebook: [notebook.ipynb](notebook.ipynb)

### 💡 Requirements:
- `datasets`
- `pandas`
- `valx`
