# 🌸 Project 15: Iris Flower Species Classification

## 🔗 Dataset
The dataset is included locally in this project folder (`dataset.csv`). It contains measurements of sepal length, sepal width, petal length, and petal width for three species of Iris flowers: setosa, versicolor, and virginica.

[🔗 Original Dataset](https://archive.ics.uci.edu/ml/datasets/iris)

## 🧠 Model
We will build a **Random Forest Classifier**, which is an easy and robust model for tabular classification tasks.

## 🧪 Notebook Execution
This notebook demonstrates how to load the dataset, train the model, evaluate its accuracy, and visualize the results.

- **Notebook**: [project-15-iris-executed.ipynb](project-15-iris-executed.ipynb) (executed locally)
- **Dataset**: [dataset.csv](dataset.csv)
